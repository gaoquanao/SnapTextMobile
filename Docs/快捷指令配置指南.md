# 拾文 · 快捷指令与操作按钮配置指南

> 目标：让「截图 → 识别 → 归档/大爆炸」用起来又快又省事。**配方已内置在 App 中，一键导入即可**（第一步），需要自定义时再在快捷指令 App 里改。

## 第零步 · 开箱即用（推荐，无需配置）

拾文内置两个「控制」，装上即可在系统里绑定：

1. **大爆炸识别**：读相册最新截图 → 打开拾文 → 弹出大爆炸选取
2. **归档最近截图**：后台识别归档，不打断当前操作

绑定方式（任选）：

- **控制中心**：长按控制中心 → 添加控件 → 拾文 → 选上述任一
- **操作按钮**（iPhone 15 Pro 及以上，iOS 18）：设置 → 操作按钮 → 左右滑动到「控制」→ 选「拾文·大爆炸识别」
- **分享面板**：截图后点左下角缩略图 → 分享 → 拾文（扩展内完成识别、选取、归档）

首次使用会请求相册权限；之后即用。

## 第一步 · 内置配方（推荐，一键导入）

**配方 A / B 已内置在 App 里**（文件随安装包分发，已完成签名，导入时无需开启「允许不受信任的快捷指令」，全程离线）：

1. 打开拾文 → **设置** → 「第二步 · 快捷指令」 → 点 **一键添加到快捷指令**
2. 系统弹出打开方式菜单 → 选择 **快捷指令**
3. 在导入页点 **添加快捷指令**，配方即出现在快捷指令 App
4. **导入后可在快捷指令 App 里任意修改**（换触发方式、追加导出动作等）

| 配方 | 动作链 | 适用 |
| --- | --- | --- |
| **拾文·大爆炸（默认）** | 截屏 → 大爆炸截图识别 | 想马上查看并整理文字 |
| **拾文·静默归档** | 截屏 → 静默归档截图 → 显示通知 | 不打断当前操作 |

**首次运行的两个系统确认**（只问一次，务必选对）：

- 「"快捷指令"想要截取屏幕」→ **允许**
- 「允许"拾文·大爆炸"将 1 张图片共享给"拾文"」→ 选 **始终允许**。若选了「允许一次」，之后每次运行都会再问，且可能被系统隐私提示拦下（快捷指令详情 → 隐私 里可补授权）

### 配方 C · 截屏全自动（零操作，最快）

自动化属于系统私有数据，**iOS 不允许导入**，需手动创建一次：

1. 快捷指令 App → 底部「自动化」→ **新建自动化**
2. 选择 **「截屏时」**（在任意 App 内截屏即触发）
3. 选择 **「立即运行」**，并关闭 **「运行前询问」**
4. 动作添加拾文 App 的 **「静默归档截图」**

配置完成后：截图瞬间自动识别归档，无需任何按键。

### 附 · 手动搭建配方 A / B（备选）

导入失败或想完全自己配置时，在设置页「手动搭建配方」里可展开逐步说明：

- **配方 A**：新建快捷指令 → 动作 1「截屏」→ 动作 2 搜「拾文」选「大爆炸截图识别」，把「截图」参数设为上一步输出
- **配方 B**：新建快捷指令 → 动作 1「截屏」→ 动作 2「静默归档截图」（「截图」参数设为上一步输出）→（可选）动作 3「显示通知」

### 备选 · 相册自动收集（App 内置，无需快捷指令）

打开拾文 → 设置 → **相册自动收集**：

- 监控范围选「系统全部截图」或指定一个相簿（可先在照片 App 建一个「拾文收集箱」相簿，把想收集的图都存进去）
- 前台期间新增图片实时识别归档；退到后台后由系统择机补漏（需开启 设置 → 通用 → 后台 App 刷新）
- 重复截图会自动查重，不会产生重复归档

### 可选 · 归档后清理相册（截图清理）

设置 → **截图清理** → 开启「归档后删除源截图」：

- 只对**静默通道**生效：相册自动收集、控制中心控件、静默归档的兜底路径；分享与手动导入的图片不动
- 每次删除 iOS 都会弹出系统确认，删除的图片进入「最近删除」保留 30 天，可随时找回
- 开启后运行摘要会显示「已清理 N 张」

> 还有第三个动作 **提取截图文本**：只返回纯文本，方便你自己串「创建备忘录」「添加到提醒事项」等任意动作。

## 第二步 · 绑定触发方式

### 操作按钮（iPhone 15 Pro / 15 Pro Max / 16 全系 / 16e）

1. **设置 → 操作按钮**
2. 左右滑动选到 **快捷指令**
3. 选择 **拾文·大爆炸**（或拾文·静默归档）

完成后：长按侧键下方那颗按钮 → 截屏并立即识别。

### 轻点背面（所有全面屏机型）

1. **设置 → 辅助功能 → 触控 → 轻点背面**
2. 「轻点两下」或「轻点三下」→ 选 **拾文·大爆炸**

### 控制中心控件（iOS 18+，免搭快捷指令）

1. 长按控制中心进入编辑 → **添加控件**
2. 找到 **拾文** → 添加 **「拾文·归档最近截图」**
3. 该控件直接读取**相册中最近一张截图**归档，无需截屏动作；首次使用请先打开拾文 App 完成相册授权

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 点「一键添加」没有反应 | 重启 App 重试；仍不行就直接用设置页「手动搭建配方」按步骤创建 |
| 运行配方每次都要确认共享图片 | 第一次提示时选「始终允许」；若已选过「允许一次」，重跑一次并改选「始终允许」，或在快捷指令详情 → 隐私里授权拾文 |
| 运行提示「快捷指令不能访问拾文」 | 快捷指令详情（ⓘ）→ 隐私 → 允许访问拾文；或删除配方后重新导入并选「始终允许」 |
| 运行快捷指令提示「无法截屏」 | 系统设置 → 快捷指令 → 确认允许；或重新运行一次并在弹窗中允许截屏 |
| 「处理最近截图/归档最近截图」报相册权限 | 先打开拾文 App → 捕获页任选一次相册图片，完成授权 |
| 快捷指令里搜不到拾文的动作 | 确认真机已安装 App；动作列表搜索框输入「拾文」或「SnapText」 |
| 分享面板里没有拾文 | 截图后点左下角缩略图 → 分享 → 面板底部横向列表滑到最右 → 「编辑操作…」里把拾文加入收藏 |
| 导出 Obsidian 无反应 | 确认已安装 Obsidian，并在拾文「设置 → 导出」填写 Vault 名称 |
| 未装目标应用时导出 | 拾文会把 Markdown 全文复制到剪贴板并提示 |
| iOS 26 机型没有 AI 摘要 | 设置 → Apple Intelligence 与 Siri → 开启 Apple Intelligence；拾文「设置 → 端侧 AI」会显示当前提取模式 |

## 隐私说明

截图识别（Vision OCR）、关键词/摘要提取、存储全部在设备本地完成；导出仅在用户主动点击时把内容交给对应 App 或系统分享面板。App 无任何网络请求。
